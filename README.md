Talabat Delivery Zone Intelligence

Project Description

This project uses Machine Learning to discover different types of Talabat delivery zones based on their operational data.

The goal is to identify hidden patterns in delivery zones and turn the results into useful business recommendations.
Dataset
Each row represents one delivery zone.

The dataset includes features such as:
- Average daily orders
- Peak-hour orders
- Average order value
- Delivery distance
- Delivery time
- Weekend orders
- Cancellation rate
- Restaurant count
